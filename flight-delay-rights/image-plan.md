# Image Plan

## Cover

- Role: 首图，先把“延误时别只盯赔偿”这个核心误区打出来
- Main message: 真正更重要的权益是信息、退改、食宿、证明和机上延误保障
- Prompt notes: 机场候机区大屏显示航班延误，旅客看手机或登机牌，蓝白航空信息图风格，少量橙色强调，画面干净、专业、可信

## Body Figures

### Figure 1
- Section: 旅客最常用的6项核心权益总览
- Image type: 分类信息图
- Main message: 信息通知、退改签、食宿、证明、机上延误、争议确认是延误后的核心处理框架
- Prompt notes: 6宫格信息图，图标明确，层级清晰，适合正文中段快速建立认知

### Figure 2
- Section: 食宿服务边界
- Image type: 对比图
- Main message: 航空公司原因和非航空公司原因下，餐食住宿责任不同；经停延误和备降属于特殊情况
- Prompt notes: 左右对比布局，突出“谁负责”“什么情况例外”，蓝白主色，橙色做关键差异提示

### Figure 3
- Section: 机上延误时的关键节点
- Image type: 流程时间图
- Main message: 30分钟通知、2小时饮水食品、3小时且无明确起飞时间可安排下机
- Prompt notes: 时间轴风格，机舱场景元素，数字节点醒目，适合让读者一眼记住

### Figure 4
- Section: 延误后最实用的处理顺序
- Image type: 清单图
- Main message: 先看通知、再办退改、再问食宿、再开证明、再留证据
- Prompt notes: 这张图兼作文末收藏海报，适合文末插入和转发，视觉上更像“操作清单”

## Closing Poster

- Needed: Yes
- Main message: 遇到延误别只问赔不赔，先按顺序把关键权益拿到手
- Prompt notes: 使用 Figure 4 作为文末收藏海报，无需额外单独生成第二张总结图
