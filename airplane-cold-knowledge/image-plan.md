# Image Plan

## Cover

- Role: 首屏抓住好奇心，让读者一眼知道这是“飞机冷知识总览”。
- Main message: 把“会飞、热水、厕所、圆窗、机翼”五个问题压在同一张视觉里。
- Prompt notes: 蓝白航空信息图风格；客舱窗、机翼、热水杯、厕所图标并置；标题大字清晰；适合作为封面和正文首图。

## Body Figures

### Figure 1

- Section: 飞机为什么能飞起来
- Image type: 逻辑拆解信息图
- Main message: 升力、推力、重力、阻力四个力量一起工作，飞机不是“靠飘起来”。
- Prompt notes: 机翼侧视图、气流箭头、四力标签；重点突出“发动机往前推，机翼负责造升力”。

### Figure 2

- Section: 热水系统 + 厕所系统
- Image type: 双栏对照信息图
- Main message: 热水来自饮用水系统，厕所废弃物进入密封污物箱，两套系统完全不是一回事。
- Prompt notes: 左侧画厨房热水流程，右侧画真空厕所与污物箱；加“可饮用系统”“密封储存”“落地清运”等关键词。

### Figure 3

- Section: 圆窗 + 机翼弹性
- Image type: 原理示意图
- Main message: 圆角窗用来分散压力，机翼可弯曲是为了吸收载荷，不是快断了。
- Prompt notes: 窗框受力对比、机翼弹性弯曲示意；语气要安抚而不是惊悚。

## Closing Poster

- Needed: 是
- Main message: 把5个冷知识压缩成一张值得收藏的小抄。
- Prompt notes: 五条短句纵向排布，蓝白底，少量橙色强调，适合手机端收藏。
