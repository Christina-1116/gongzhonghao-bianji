# 公众号创作 README

## 这个号在做什么

这是一个以航空出行科普为核心方向的公众号。

内容不是写给业内人看的，也不是写给极少数发烧友看的，而是写给普通读者的：
他们会坐飞机，会遇到值机、托运、选座、转机、行李、宠物出行、特殊旅客服务这些真实问题；
他们不想看太专业、太硬、太像规定原文的内容；
他们想要的是：

1. 一眼看懂
2. 立刻能用
3. 看完少踩坑

所以这个号的内容核心，不是“展示知识”，而是：

**把复杂规则翻译成普通人能直接执行的判断。**

---

## 内容定位

账号内容应长期围绕下面几类主题展开：

1. 航空出行避坑
2. 飞机乘坐体验优化
3. 航司规则翻译
4. 特殊旅客与特殊场景服务
5. 行李、宠物、选座、值机、转机等高频问题
6. 旅行中的“看起来小，实际最容易踩坑”的细节

内容角度优先级：

1. 普通人真的会搜的问题
2. 看完能直接减少失误的问题
3. 规则复杂、认知混乱、最容易误会的问题
4. 有传播感和评论区讨论空间的话题

不优先做的内容：

1. 过度资讯化、新闻搬运式内容
2. 业内术语堆砌、像培训材料的内容
3. 只罗列规则、不提供判断顺序的内容
4. 空泛旅行鸡汤

## 写作标准

### 1. 去 AI 味

文章不能像“整理材料”，也不能像“说明书”。

避免这些问题：

1. 句式太平均
2. 段落太工整，像模板拼接
3. 总结过多，判断太少
4. 爱用“首先、其次、最后”硬分段
5. 用词太像客服、太像通知、太像百科

应该追求的感觉：

1. 像一个很懂航空出行的人，帮普通读者把事讲明白
2. 有判断、有取舍、有提醒，不只是复述
3. 说人话，但不油腻
4. 有传播感，但不夸张失真

### 2. 爆款文章标准

每篇文章都要尽量满足这几个条件：

1. 标题有明确冲突点或误区点
2. 开头 3 段内让读者知道“这篇能帮我解决什么”
3. 正文不能像论文，要有节奏变化
4. 每一节都要有一个可以被记住的判断句
5. 文末最好能留下“收藏价值”或“评论冲动”

最常用的爆款结构：

1. 先说大家最容易想错的地方
2. 再拆真实规则或真实逻辑
3. 中间用图帮助读者快速理解
4. 最后给出能直接执行的清单或口诀

### 3. 标题风格

标题要尽量满足这几种特征中的一种或多种：

1. 误区反转
2. 强结果导向
3. 具体问题直接命中
4. 普通人熟悉的场景切入

示例方向：

1. “最容易踩坑的不是……而是……”
2. “很多人第一步就想错了”
3. “不是所有……都可以……”
4. “一篇讲清……”
5. “下次别再盲选了”

标题不要写成：

1. 纯概念型
2. 纯知识点罗列型
3. 太像资讯播报
4. 太泛，没有具体使用场景

## 文章结构原则

一篇成熟的公众号文章，通常建议有这几层：

1. 标题
2. 副标题 / 导语
3. 首图
4. 误区切入
5. 分章节解释
6. 中段插图打断阅读疲劳
7. 最后一节做清单、口诀或直接建议
8. 文末说明
9. 文末互动引导

正文节奏上，要避免整篇都像同一种密度。

应该主动安排：

1. 短段落
2. 判断句
3. 金句式强调
4. 小结型过渡
5. 插图作为阅读喘息点

## 配图原则

这个号的图，不是装饰图，而是信息图。

配图的作用是：

1. 降低理解成本
2. 让读者在 3 秒内抓住章节重点
3. 制造视觉停顿，提高完读率
4. 增强收藏和转发价值

### 配图风格

整体视觉方向：

1. 蓝白航空感
2. 极简、高级、克制
3. 信息密度高，但阅读顺序非常清楚
4. 不做花哨插画堆砌
5. 以“可执行信息版面”为第一优先级

可以参考的视觉关键词：

1. 苹果式信息克制
2. 高桥流式版面秩序
3. 杂志级留白
4. 航空科普信息图
5. 海报化的信息组织

### 配图内容结构

配图通常适合这几种类型：

1. 分类图
2. 流程图
3. 对比图
4. 清单图
5. 人群建议图
6. 避坑图

### 配图禁忌

1. 不要只是好看，没信息
2. 不要字特别多，像把正文塞进图里
3. 不要层级混乱，读者不知道先看哪里
4. 不要把视觉重心放错，次要信息比结论更抢眼
5. 不要出现文字溢出边框、留白不一致、字体大小乱跳

## 当前已经形成的工作方法

这套公众号内容，已经形成了一套可复用流程。

### 第一步：定题

先判断题目是否满足三个条件：

1. 普通人真的会遇到
2. 读者容易误会
3. 看完能立刻少踩坑

### 第二步：定核心判断

每篇文章都要先提炼一句最核心的话。

比如：

1. 带宠物坐飞机，最容易错的不是手续，而是第一步分类就错了
2. 选座不是找完美位置，而是在稳、静、宽之间做取舍

这句话决定全文方向，也决定配图结构。

### 第三步：重写成公众号语言

把原始素材从“信息”改写成“文章”：

1. 去掉生硬和 AI 味
2. 增强判断句
3. 做节奏变化
4. 保留传播感
5. 让每一节都有明确功能

### 第四步：设计配图

根据正文逻辑制作 3 到 5 张正文插图。

正文插图通常放在：

1. 概念分流处
2. 流程解释处
3. 对比判断处
4. 文章收束处

### 第五步：生成发布版页面

目前已采用的交付形式：

1. `xxx-wechat-article.md`：正文稿
2. `xxx-wechat-direct-copy.html`：公众号粘贴版
3. `xxx-output.html`：网页阅读版
4. `assets/...png`：公众号上传用配图
5. `assets/...svg`：可继续修改的源文件
